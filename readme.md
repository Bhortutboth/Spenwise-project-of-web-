# SpendWise - JavaScript Foundation

## Project Description

SpendWise is a Personal Budget and Expense Tracker designed to help users manage their monthly budget and expenses.

This week's assignment transforms the SpendWise project from a visual webpage into an interactive application using JavaScript.

The application allows users to enter their monthly budget and total expenses. JavaScript then calculates and displays the remaining balance in the browser console.

## Technologies Used

- HTML
- CSS
- JavaScript
